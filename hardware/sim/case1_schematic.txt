================================================================================
 CASE 1 — ASCII SCHEMATIC แยกโมดูล 1–6  (OPA4134PA + DD1718PA ±15V)
================================================================================
 ที่มา: docs/CASE1_WIRING.md (ค่าและรูอยู่ที่นั่น — ไฟล์นี้ไว้ "เข้าใจวงจร" ไม่ใช่ "เสียบรู")
 สถานะ 2026-11-25: แผนเท่านั้น ยังไม่ได้ต่อ/วัดจริง
 ตัวเก็บประจุที่มีจริง: 0.1 µF และ 100 pF ไม่มีขั้วเท่านั้น → E1–E4 = 0.1 µF (หรือเว้น)

 คำย่อ:  "โมดูล N" = กลุ่มงาน ;  M1, M2 = จุดกลางระหว่าง R สองตัว (ไม่ใช่โมดูล)

 U1 = OPA4134PA (DIP-14) ขา:
   1 OUT A   2 −IN A   3 +IN A   4 V+ (+15V)   5 +IN B   6 −IN B   7 OUT B
   8 OUT C   9 −IN C  10 +IN C  11 V− (−15V)  12 +IN D  13 −IN D  14 OUT D

--------------------------------------------------------------------------------
 ภาพรวม
--------------------------------------------------------------------------------

 GPIO25 (DAC) ─► [โมดูล 4: ch A ×6.1 กลับเฟส] ─► node A ─► DUT ─► node B ─► [โมดูล 6: Rr] ─► GND
                        ▲                          │                │
                 [โมดูล 3: V_REF 1.65V]            ▼                ▼
                                          [โมดูล 5: ch C]    [โมดูล 5: ch D]
                                                   │                │
                                              P1 → GPIO34      P2 → GPIO35

 [โมดูล 1] 5V → ±15V        [โมดูล 2] ±15V → U1 ขา 4 / ขา 11

================================================================================
 โมดูล 1 — ไฟเลี้ยง  (CASE1_WIRING ขั้นที่ 1)
================================================================================

               D1 1N5819
 ESP32 VIN ───►|──────────────────► DD1718PA VIN
   (5V)     (a3)   (a7, ฝั่งแถบ)

 DD1718PA +Vo ──┬─────────┬──────── ราง +15V
               [C1]      [E1]
              0.1µF     0.1µF
 DD1718PA GND ──┴─────────┴──────── ราง GND ──── ESP32 GND
               [C2]      [E2]
              0.1µF     0.1µF
 DD1718PA −Vo ──┴─────────┴──────── ราง −15V

 วัด:  a3 ≈ 4.6–5.1V   a7 4.3–4.8V   +15V: +14.4…+15.6   −15V: −14.4…−15.6   GND บน↔ล่าง 0V

================================================================================
 โมดูล 2 — ไฟเข้า op-amp  (ขั้นที่ 2, ยังไม่เสียบชิป)
================================================================================

 ราง +15V ──┬─────────────┬──── U1 ขา 4 (V+)
           [E3]          [C3]   ← C3 ชิดขา 4 ที่สุด
          0.1µF         0.1µF
 GND ───────┴─────────────┴────
           [E4]          [C4]   ← C4 ชิดขา 11
          0.1µF         0.1µF
 ราง −15V ──┴─────────────┴──── U1 ขา 11 (V−)

 วัด:  ขา 4 = +15V   ขา 11 = −15V   ขาอื่นทุกขา ~0V/ลอย (ห้ามมีขาไหนได้ ±15V)

================================================================================
 โมดูล 3 — V_REF 1.65V  (ch B = buffer, ขั้นที่ 3a)
================================================================================

 ESP32 3V3 ──┬──[R7 10k]──┬──[R8 10k]── GND
             │            │ VDIV ≈ 1.65V
             │            │        ┌─────┐
             │            └─ 5(+) ─┤     │
             │                     │ U1B ├─ 7 ──┬──► V_REF 1.65V (ไป R2, โมดูล 4)
             │              ┌ 6(−) ┤     │      │
             │              │      └─────┘      │
             │              └───────────────────┘   W6: ขา 6 ↔ ขา 7
             └──► 3V3 ไปเลี้ยง R10, R13 (โมดูล 5)

 วัด (ยังไม่เสียบชิป):  VDIV = 1.65V ±0.05
 วัด (เสียบชิปแล้ว):    ขา 7 = VDIV ±10mV

================================================================================
 โมดูล 4 — ตัวขยาย ±10V  (ch A, difference amp ×6.1, ขั้นที่ 3b)
================================================================================

                         Rf1 = 61k
                 ┌──[R3 51k]── M1 ──[R4 10k]──┐
                 │           (แถว 17)         │
                 │         ┌─────┐            │
 GPIO25 ─[R1 10k]┴─ 2(−) ──┤     │            │
  (DAC)                    │ U1A ├─ 1 ────────┴───► node A
 V_REF ──[R2 10k]┬─ 3(+) ──┤     │
 (ขา 7)          │         └─────┘
              [R5 51k]
                 │ M2 (แถว 28)     Rf2 = 61k
              [R6 10k]
                 │
                GND

 V_A = 6.1 × (V_REF − V_DAC)   (กลับเฟส: DAC ขึ้น → node A ลง; firmware กลับ LUT ให้แล้ว)
 ลำดับ Rf1: ขา 2 → R3 51k → M1 → R4 10k → ขา 1   (ห้ามสลับ ไม่งั้นรูผิด)
 ลำดับ Rf2: ขา 3 → R5 51k → M2 → R6 10k → GND

 วัด (เสียบชิป, DAC = 128):  ขา 3 ≈ 1.42V   ขา 2 ≈ 1.42V   node A ใกล้ 0V (< ±0.5V)
   node A = +1.65V → ขาด R5/R6 ;  node A ≈ ±13V → ch A อิ่มตัว (R ขาด / ขา 2-3 สลับ)

 P = 1.49V + 0.099 × V_node     (node 0V → 1.49V ; ±10V → 0.50 / 2.48V)
 C5 กับ C6 ต้องค่าเดียวกันเสมอ (100 pF ตอนนี้ → 1 nF พร้อมกันทั้งคู่)

 วัด (ยังไม่เสียบชิป):  P1 = P2 ≈ 1.65V  (R9/R12 ลอย → 3.3 × 22/44)
 วัด (เสียบชิป):        P1 = P2 = 1.49V ±0.05

================================================================================
 โมดูล 6 — DUT + Rr  (ขั้นที่ 3d)
================================================================================

 node A ──(i40)──[ DUT ]──(i44)── node B ──JS──┬─[Rr1 1k]─── GND  (ค่าเริ่มต้น)
                                               ├─[Rr2 10k]── GND
                                               └─[Rr3 100k]─ GND
   JS = สายเส้นเดียว ย้ายปลายไป Rr ที่ต้องการ    ไม่ใช้ Rr 100Ω (DUT ช็อต = 100mA เกิน op-amp)

 V_DUT = V_A − V_B        I = V_B / Rr

 วัด (ไม่มีไฟ):  i44 ↔ GND = ค่า Rr ที่ JS เลือก
